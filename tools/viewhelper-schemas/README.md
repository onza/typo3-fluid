# ViewHelper schema generator

Produces JSON schemas for Core namespaces (`f`, `core`, `formvh`), consumed by `builtin/server.js`.

Generator adapted from [FriendsOfTYPO3/vscode-fluid-language](https://github.com/FriendsOfTYPO3/vscode-fluid-language) (`fluid/`).

```bash
./tools/generate-viewhelper-schemas.sh
```
